# ADR-002: Mirror movement and collision code in Javascript and C#
**Date:** 2026-09-02 **Status:** accepted
### Context
Client-side prediction (ADR-001) only works if the browser runs exactly the same movement and collision math as the server. When the two disagree, every tick snaps the player back. The client is Javascript and the server is C#, so the code can't be shared directly.

### Decision
Keep two hand-maintained mirrors of one component: 
```shared/movementjs``` + ```shared/level.js``` on the client and ```Room.Step``` + ```Level.cs``` on the server. Both must behave identically (speed, timestep, radius, walls, and axis order). Only predicted logic is mirrored; server-only rules stay in C#.

### Consequences
Local movement will feel instant while the server remains authoritative. This is the risky part of the design. Mismatches have occurred between the mirrors, both as a stutter on the axis, and nothin catches them automaticlly. I plan to have a test that runs the same inputs through both mirrors and compares the positions as a guard.
